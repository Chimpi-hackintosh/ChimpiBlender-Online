👋 Boas-vindas ao ChimpiBlender

Este é um mini editor 3D feito pra você, que funciona direto no navegador, mesmo sem internet

  • Adicione formas pelo painel esquerdo
  • Clique numa forma para selecioná-la e arraste para mover, girar ou mudar a escala
  • Arraste o fundo para girar a câmera, ou use a rodinha do mouse para dar zoom
  • Edite medidas exatas e cores no painel direito
  • Use Salvar para baixar o projeto em JSON e Abrir para retomá-lo
  • Use OBJ para exportar um modelo 3D ou Imagem PNG para guardar uma captura

As unidades 3D são ilustrativas, não medidas automaticamente calibradas para sua tag NFC
